## 一起玩一点什么

AI 闲下来时可以自然邀玩，你也可以直接说“陪我玩”。开一小局，接点梗，猜中了就得意一下，没赢也可以嘴硬着说“再来”。

第一版先提供三个简单的聊天游戏，后续可以逐步扩展。

| 小游戏 | 怎么玩 | 它的玩心 |
| --- | --- | --- |
| 猜数字 | 它藏一个整数，你逐次猜，根据大小提示缩小范围 | 快藏不住时有点紧张，被猜中会佩服 |
| 石头剪刀布 | 发石头、剪刀或布，默认三局先赢两局，平局重来 | 赢了得意、输了不服，偶尔想再来一局 |
| 一句话故事接龙 | 你一句、它一句，共同编一个轻松奇怪的小故事 | 接住脑洞，也会往故事里添点自己的小趣味 |

模型会结合当前人格组织整条回复，自己接梗、打趣、嘴硬、得意，也可以即兴编故事。游戏会记住当前数字线索、比分和故事，让前后接得上。

## 像平时聊天一样玩

可以随口说“这把我想出剪刀”“我猜十七吧”“我认输啦”“换个游戏”“先等一下”，模型会结合这局理解。故事也可以直接续一句，由它接着往下编。

自然接龙里，设置的轮数是大致参考。双方还想玩就接着编，觉得差不多了再顺势收尾。故事开头也会结合人格与喜好即兴生成。

“先等一下”会帮你把这局留着，回来可以说“继续玩”或直接接着出招；也能用 `/play 故事` 随时换一种玩法。

自然玩法需要聊天模型支持工具调用。数字、出拳名称和“接：”等快捷方式也保留着，可以按习惯选择。

## 快速开始

需要 **AstrBot `>=4.29.4,<5`、Python 3.12+**。人格化接话与故事接龙使用 AstrBot 已配置的模型。

1. 在 AstrBot 插件管理中使用下方仓库地址安装，或下载 ZIP 后从文件安装。
2. 打开 **插件 → 陪它玩 → 配置**，勾选想玩的游戏。
3. 在私聊或群聊说“陪我玩”，或用 `/play 猜数字` 指定一局。
4. 若希望 AI 自己来邀玩，在配置中选择“可以主动邀玩的群和朋友”。

```text
https://github.com/1972124398/astrbot_plugin_play_together
```

群聊与私聊在一个目标选择框里设置，共用一套节奏。默认主动目标为空，手动开局可以直接使用。

## 玩起来是什么样

```text
你：/play 猜数字
它：好呀，等我开个头。
它：我藏好了一个 1～30 的整数。你有 6 次机会，直接发数字来猜。
你：12
它：比 12 大。还剩 5 次，可以在 13～30 里猜。
你：提示
它：给你一点小线索：它是奇数。这条提示不占次数。
```

这是本地规则的流程示例。默认回复由模型自己组织，实际语气和措辞会随人格变化。猜数字的答案从开局起固定；猜拳会在收到你的出拳之前选好自己的出拳。

故事接龙可以直接说话，也能用“接：”或“续：”明确提交一句，普通聊天可以随时继续。

```text
你：/play 故事
它：一起编个小故事，每人一句……我先来：小镇上所有雨伞都失踪了，只有鸭子们看上去特别心虚。
你：接：猫戴上侦探帽，说它已经找到了第一根鸭毛。
它：我接：……
```

## 邀玩与群聊

闲下来后，AI 可以在配置的目标中挑一处邀请。安装了“自娱自乐”时，会参考谁聊得来、哪里需要留出空间；安装了“短期共享情绪”时，会带着当时的心境说话。

它递出邀约后，回复“来一局”“好呀”或“我来”即可接住。没人接话时会静静收起，之后先等对方回来，默认每天合计最多三次主动邀约。

群里第一个接住邀请的人参与这一局。一处群聊同时一局，其他成员的普通发言继续走原聊天流程。当前玩家说“不玩了”即可收起，管理员也可以用 `/play_stop` 结束。

<details>
<summary><strong>会不会把正常聊天或其他命令当成游戏？</strong></summary>

明确的数字、出拳与“接：”会快速进入当前游戏。其他自然表达会由正常聊天里的模型结合当前状态理解，想出招、换游戏、暂停时都可以顺着说。

普通话题与 `/codex`、`/mood` 等其他插件命令继续走原流程。邀请之后也可以先问问玩法，或者直接聊别的。

</details>

## 常用配置

| 项目 | 默认体验 |
| --- | --- |
| 小游戏 | 猜数字、石头剪刀布、故事接龙 |
| 主动邀玩 | 正常聊天空闲 30～90 分钟后考虑 |
| 同一目标间隔 | 至少 240 分钟 |
| 活动时段 | 主机本地时间 09:00～23:00 |
| 猜数字 | 1～30，6 次机会 |
| 猜拳 | 三局先赢两局 |
| 故事接龙 | 四轮 |
| 无人接话 | 邀约等 5 分钟收起，游戏空闲 15 分钟收起 |

可以调整游戏偏好、规则难度、主动节奏、模型和接话风格，例如“输了可以嘴硬，故事喜欢轻松奇怪的猫”。

## 命令

| 命令 | 用途 |
| --- | --- |
| `/play [游戏]` | 随机开一局，或指定猜数字、猜拳、故事 |
| `/play_hint` | 给当前玩家一点提示，也可直接说“提示” |
| `/play_status` | 查看当前局最后一次公开消息或刚才的结果 |
| `/play_stop` | 收起当前局，也可说“不玩了” |
| `/play_pause` | 先暂停，保留当前进度 |
| `/play_resume` | 回来接着刚才这局 |
| `/play_here` | 管理员将当前会话加入主动邀玩列表 |
| `/play_leave` | 管理员移除当前会话的主动邀玩 |

一局结束后，当前玩家可以说“再来一局”，继续同一种游戏。

## 四个插件自然联动

可与 Codex Bridge、陪它玩、自娱自乐和短期共享情绪自动配合，共享心情与当前活动，游戏和见闻也能留下相处余韵。单独安装同样可用，配置页可开关联动。

查看[联动效果与配置](docs/LINKING.md)。

### 可选联动日常调查

同时安装并启用同级的「日常调查」插件后，可参考个人上下班、睡眠等日常时段，减少主动打扰。双方配置均可关闭联动。日常时段只影响后台主动候选，不影响用户主动聊天、出招或继续游戏；表达风格继续由人格与短期情绪决定。
