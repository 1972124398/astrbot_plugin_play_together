# 配置参考

[返回首页](../README.md) · [工作方式与扩展](DEVELOPMENT.md)

在 AstrBot **插件 → 陪它玩 → 配置** 打开原生配置窗口。群聊和私聊使用同一个 UMO 选择列表，也可先在目标会话用 `/sid` 查询，或由管理员发送 `/play_here` 加入。

## 配置项

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `enabled` | `true` | 启用游戏与邀玩 |
| `auto_invite` | `true` | 允许 AI 在已选择的目标中主动邀请 |
| `targets` | `[]` | 统一群聊与私聊邀玩目标 |
| `games` | 三种全选 | `number`、`rps`、`story` |
| `provider_id` | 空 | 留空跟随当前会话模型 |
| `model_voice` | `true` | 模型结合公开结果自由组织游戏回复 |
| `natural_play` | `true` | 让聊天模型理解自然表达与即兴玩法 |
| `play_preferences` | 空 | 玩耍口吻和故事风格偏好 |
| `idle_min_minutes` | `30` | 最早开始考虑邀玩的空闲时间 |
| `idle_max_minutes` | `90` | 最晚开始考虑的空闲时间 |
| `target_gap_minutes` | `240` | 同一目标再次主动邀请的间隔 |
| `daily_invites` | `3` | 所有目标合计的每日邀约次数，0 不限制 |
| `active_start_hour` | `9` | 主动邀玩开始时间 |
| `active_end_hour` | `23` | 主动邀玩结束时间，和开始相同表示全天 |
| `invitation_minutes` | `5` | 等待接住邀请的时长 |
| `game_idle_minutes` | `15` | 一局没有新操作多久先收起来 |
| `pause_minutes` | `60` | 暂停时帮玩家留多久当前进度 |
| `number_upper` | `30` | 猜数字最大值 |
| `number_attempts` | `6` | 猜数字机会数 |
| `rps_best_of` | `3` | 可选 1、3、5，先赢过半局数结束 |
| `story_rounds` | `4` | 自然接龙的大致长度参考 |
| `voice_timeout_seconds` | `8` | 人格化或故事续句的最长等待 |
| `send_timeout_seconds` | `30` | 平台发送的等待时间 |

所有时间以 AstrBot 主机本地时间为准。手动开局不受主动邀玩的活动时段与每日次数影响。

## 常见问题

### 不主动邀请

先选择目标，确认自动邀玩开启、目标平台支持主动发送，并检查活动时段和空闲时间。正在玩一局、有人正常聊天、或“自娱自乐”正在处理活动时，会暂缓邀玩。模型也可以选择这次先不邀。

若上次邀约没人接住，会先等对方正常回来聊天。可以手动说“陪我玩”开始，无需等下一次主动邀请。

### 群聊怎样加入

第一个在邀请期间说“我来”或“来一局”的人接住这一局，之后只接收该玩家的游戏操作。其他人的发言继续正常聊天，避免大家的数字或“布”混在一起。以后可以在游戏接口基础上扩展多人玩法。

### 想边玩边聊

可以直接说其他话题，也可以随口提出换游戏、暂停、认输或接着玩，聊天模型会结合当前状态理解。故事可以直接续一句；“接：”“续：”、数字与出拳名称仍可快捷使用。

自然玩法需要当前聊天模型支持工具调用。模型可以理解“我猜十七”“这把就出剪刀吧”等话，再调用游戏动作，接着用自己的语气回复。可在配置页关闭自然玩法，沿用快捷操作。

### 想暂停、换玩法或认输

“先等一下”会保留当前进度，默认帮你留一小时。回来可以说“继续玩”，也能直接接着出招。说“换个游戏”或 `/play 故事` 可以换一种玩，“我认输啦”可以揭晓或收尾。

自然故事接龙的轮数是参考，模型会结合双方兴致决定要不要继续，觉得该收尾时再编个结尾。故事开头、后续脑洞与情绪都交给模型发挥。

### 收不到后台游戏消息

确认普通主动消息能够通过平台发送。微信 Native 使用其已有发送接口，群聊能力以适配器为准。数字等操作处理后会停止这一条输入的普通 LLM 回复，游戏结果在后台发回当前会话。

### 模型很慢或不可用

快捷操作的模型接话超时后使用本地规则话术。故事续句超时会给一个本地续句，方便继续接下去。可以在配置中选择独立模型，或关闭模型接话使用本地回复。

### 重启后能不能继续

未过期的游戏状态会保留，包括固定答案和已经选好的出拳；不会自动回放旧消息。可以用 `/play_status` 看最近公开状态，或先结束再开一局。

## 拟人插件联动

`interop_enabled` 默认开启，自动发现可用同伴；关闭后独立使用。`interop_gap_minutes` 默认 10 分钟，参考所有同伴最近主动开口的时间，0 表示不额外等待。前台只读取状态与排队，感受评估在后台完成。详见[四插件联动](LINKING.md)。
